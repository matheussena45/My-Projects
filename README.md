## 🎮 Interactive Games & Event Applications

Production-ready 2D games engineered for **corporate events, touchscreen totems, and kiosk environments**. Built with a focus on high user engagement, 100% offline reliability, and business lead generation.

### 🛠️ Key Technical Highlights
* **Engine & Graphics:** Developed with **Phaser 3** utilizing **WebGL / Canvas 2D**, scene management, and **Arcade Physics**.
* **Kiosk / Totem Optimization:** Locked aspect ratios and custom **Touch Events API** handling to eliminate native browser zoom or double-tap gestures on touchscreens.
* **100% Offline-Ready:** Uses **Web Storage API (`localStorage`)** for session persistence and leaderboards without relying on external network connection.
* **Lead Gen & Administration:** Dynamic **QR Code generation** for post-game user conversion, plus a **PIN-protected admin modal** for staff resets.
